# 搜索覆盖 + 分页 + UI 改进 设计规格

日期: 2026-06-10 | 状态: 已确认

## 概述

对"青岛公司发现"工具进行四项改进：扩大搜索覆盖、结果分页、标记开关、项目图标。

## 一、网格搜索

### 问题
- 单点 25km 圆形搜索无法覆盖不规整行政区（如狭长的黄岛区）
- `types=170000` 限定"公司企业"分类，遗漏其他分类下的工厂
- 每区最多 200 条（8页×25），繁华区域大量遗漏

### 方案
每个行政区生成 3×3 网格搜索点，多个 15km 小圆拼合覆盖全区。

### 实现细节
- 行政区由 Geocoder 获取中心点 (lng, lat)
- 以中心为基准，生成 9 个网格点，间距 0.11°（约 12km）
- 每个格点发起 around 搜索，半径 15km（重叠覆盖不留空隙）
- 去掉 `types` 参数（不限制行业分类）
- 传入 `keywords=公司|工厂|企业|科技|工程|制造` 辅助过滤
- 单点翻页上限 20 页（500 条/点）
- 请求间隔 300ms

### 改动文件
- `index.html` — `getSearchTargets()` 和 `startSearch()` 函数

## 二、结果分页

### 设计
- 每页 50 条
- 列表底部翻页栏：`[<] [1] [2] [3] ... [N] [>]  共 X 条`
- 翻页时地图自动适配显示当前页公司
- 超出 7 页时显示省略号

### 改动文件
- `index.html` — 新增分页 HTML + renderPagination() 函数

## 三、标记开关

### 设计
- 工具栏新增按钮 `[显示标记 ✓]`
- 默认开启（显示当前页标记在地图上）
- 关闭后清除所有标记，地图空白
- 与分页联动：翻页时如果开关开启则更新标记

### 改动文件
- `index.html` — 新增按钮 + toggleMarkers() 函数

## 四、Favicon

### 设计
- 内联 SVG：地图定位针 + 建筑轮廓
- 配色：蓝色 (#1677ff) 与页面主色调一致

### 改动文件
- `index.html` — `<head>` 新增 `<link rel="icon">` 内联 SVG

## 五、不涉及

- 不改变打分逻辑
- 不改变 CSV 导出
- 不改变地图 API Key
- 不改动其他 HTML 文件
