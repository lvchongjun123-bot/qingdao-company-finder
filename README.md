# 青岛公司发现 - 高德地图

基于高德地图的公司搜索与评分工具。

## 功能

- 🔍 **四种搜索模式**：行政区、拉框、画圆、视野
- 📊 **智能评分**：综合企业性质、规模、福利、距离、联系方式等维度打分
- 🗺️ **地图可视化**：搜索结果在地图上排序标注
- 📥 **CSV 导出**：一键导出搜索结果
- 🔗 **招聘链接**：快速跳转 BOSS直聘、智联招聘、前程无忧

## 使用方式

直接访问：`https://<你的用户名>.github.io/<仓库名>/`

或本地打开 `index.html` 即可使用（需要网络加载高德地图 API）。

## 技术栈

- 纯前端 HTML/CSS/JS
- 高德地图 JS API 2.0
- 高德 Web服务 API (Place Search)
- GitHub Pages 部署
